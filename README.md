# 🌸 posyandu-kuncup-harapan

**posyandu-kuncup-harapan** is a comprehensive, high-performance management system designed to digitalize community health services. This platform empowers health workers at "Kuncup Harapan" to record, monitor, and analyze health data for both infants and seniors with extreme precision.

### 🛡️ Core Infrastructure
- **Engine:** Bun 1.x (Ultra-fast Runtime)
- **Frontend:** React 18 + Vite + Tailwind CSS
- **State:** Zustand (Atomic State Management)
- **Security:** Strict Auth Guard & Session-based Identity
- **Reliability:** Resource-managed backend via Systemd quotas

### 🔥 Exclusive Features
- **📊 Real-time Mabes Dashboard:** Instant daily visit tracking and health statistics.
- **👶 Infant Growth Hub:** Precision Anthropometry monitoring (Weight, Height, LILA/LIKA).
- **👵 Senior Health Guard:** Critical metrics tracking (Blood Pressure, Glucose, Uric Acid).
- **🛡️ Officer Management:** Built-in User Management for health workers (Akses Petugas).
- **📝 Resilient Forms:** Anti-data-loss system with smart cleanup & refresh logic.
- **📥 Master Export:** One-click data synchronization to Excel for official reporting.
